# Chaowen 博客

一个使用 Next.js、Tailwind CSS 和 MDX 搭建的个人博客起点。

## 本地运行

```bash
npm install
npm run dev
```

文章放在 `src/content/posts` 下维护，当前主要使用 `.mdx`，后续将支持普通 `.md` 文章。生产环境已部署到自有服务器，相关记录见 `docs/05-deployment/自有服务器部署.md`。

## 亚马逊商品利润计算器

访问 `/tools/amazon-profit`，或点击顶部导航「利润计算」。页面以 `require.md` 中的英、德、法案例为默认值，支持站点开关、商品尺寸与重量、售价、汇率、VAT、佣金、FBA 配送、仓储周期与旺季月份、新品仓储减免、头程计费、采购、包装、广告及其他费用的实时计算。

费率和汇率为案例预设，需手动按实际报价调整。计算按北京时间的自然日分摊仓储，中间值不四舍五入。案例默认利润约 ¥548.47；新品全额免仓储后约 ¥1,222.82；广告开关默认关闭，预设总额 ¥600。页面包含站点明细、月度仓储明细和公式说明。

FBA 基础配送费默认按提供的费率图片自动匹配：尺寸按长、中、短边排序，结合单件重量和各站点含税售价选择低价或正常配送。英国低价上限 £10、德国 €11、法国 €12，均含边界；低价表为空的档位使用正常配送。可单独选择「只用正常配送费」或「手动填写报价」。按用户约定，长中边不超过 33×23cm 时，厚度超过 2.5cm 至 4cm 优先走大信封，超过 4cm 至 6cm 走超大信封，这两档不另设重量上限；超过 6cm 或不符合其余信封尺寸限制时，按包裹尺寸和克重匹配。薄信封超过 460g 时进入包裹档位。超出图表覆盖范围不自动估算，需手动报价。基础费匹配后仍按所填比例另加燃油与物流附加费。
