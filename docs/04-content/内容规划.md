# 内容规划

## 文章一级分类

### 技术复盘、踩坑随笔

记录真实开发过程中的问题、排查路径、错误原因和最终解决方案。

示例：ROS2 交叉编译踩坑记录、PTP 时间同步调试笔记。

### 技术科普、概念讲解

用易懂的方式解释技术概念、原理和实现过程，适合沉淀为长期可检索的知识文章。

示例：什么是 KV Cache、MVP 是什么、Transformer 手写笔记。

### 项目实践分享

记录一个项目从目标、方案、实现到结果的完整过程，强调可复现和经验总结。

示例：搭建 VitePress 文档站、awesome-gpt-image-2 使用实践。

### 学习总结、读书与调研笔记

发布经过整理、润色和结构化后的学习成果，不局限于单次阅读记录。

### 工具教程、实操分享

面向具体工具或工作流的操作教程，重点说明适用场景、步骤和常见问题。

### 个人思考、行业观察

记录个人判断、工作感受和对技术行业、产品或创作的观察。

## 分类使用原则

- 一篇文章只设置一个 `category`，避免分类页出现重复归档。
- 一篇文章可设置 2-5 个 `tags`，描述技术、主题、平台或场景。
- 如果文章同时符合多个方向，以文章的主要阅读目的作为分类依据。
- 分类描述“这是什么类型的文章”，标签描述“文章具体涉及什么”。

例如，“PTP 时间同步调试笔记”属于 `技术复盘、踩坑随笔`，标签可以是 `Linux`、`时间同步`、`网络`；“KV Cache 原理与实践”属于 `技术科普、概念讲解`，标签可以是 `AI`、`Transformer`、`推理优化`。

## 推荐 frontmatter

```md
---
title: 文章标题
date: 2026-09-03
description: 一句话摘要，用于列表页和 SEO。
category: 技术复盘、踩坑随笔
tags:
  - 技术主题
  - 使用场景
cover: /images/posts/article-cover.webp
draft: false
---
```

## 自动化方向

当前首页和文章详情页已经在构建阶段扫描 `src/content/posts/*.mdx` 并读取 frontmatter。后续可以继续基于同一套数据自动生成：

- 首页最新文章列表
- `/category/[category]` 分类页
- `/tag/[tag]` 标签页
- `/archive/[year]/[month]` 月度归档
- 文章详情页和上一篇/下一篇导航
