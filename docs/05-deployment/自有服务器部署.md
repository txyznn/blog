# 自有服务器部署

本文记录 ChaoWen Notes 部署到自有服务器的标准流程。当前项目使用 Next.js + MDX，生产环境采用 Node.js、PM2 和 Nginx。

## 部署架构

```text
浏览器 -> 域名 -> Nginx:80/443 -> PM2 -> Next.js:3000
```

`.next` 和 `node_modules` 不需要提交到 Git，服务器拉取代码后重新安装依赖并构建即可。

## 前置条件

- Linux 服务器（以下命令以 Ubuntu/Debian 为例）
- 域名完成备案（如服务器所在地要求备案）
- 域名 A 记录指向服务器公网 IP
- 防火墙放行 `80` 和 `443` 端口

## 安装运行环境

Next.js 16 需要 Node.js 20.9 或更高版本，推荐 Node.js 22：

```bash
sudo apt update
sudo apt install -y git nginx
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
source ~/.bashrc
nvm install 22
nvm use 22
node -v
npm -v
```

## 首次部署

```bash
cd /var/www
git clone git@github.com:txyznn/blog.git
cd blog
npm ci
npm run build
```

如果服务器没有配置 GitHub SSH，可以使用 HTTPS 地址克隆仓库。构建成功后可先用 `npm run start` 验证，Next.js 默认监听 `127.0.0.1:3000`。

## 使用 PM2 运行

```bash
npm install -g pm2
cd /var/www/blog
pm2 start npm --name chaowen-blog -- start
pm2 save
pm2 startup
```

常用命令：

```bash
pm2 status
pm2 logs chaowen-blog
pm2 restart chaowen-blog
```

## 配置 Nginx

创建 `/etc/nginx/sites-available/chaowen-blog`：

```nginx
server {
    listen 80;
    server_name txyznn.xyz www.txyznn.xyz;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用并检查：

```bash
sudo ln -s /etc/nginx/sites-available/chaowen-blog /etc/nginx/sites-enabled/chaowen-blog
sudo nginx -t
sudo systemctl reload nginx
```

## 配置 HTTPS

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d txyznn.xyz -d www.txyznn.xyz
sudo certbot renew --dry-run
```

Certbot 会自动申请证书并配置 HTTP 到 HTTPS 的跳转。

## 日常更新

```bash
cd /var/www/blog
git pull --ff-only
npm ci
npm run build
pm2 restart chaowen-blog
```

新增 MDX 文章放在 `src/content/posts/`，文章图片放在 `public/images/`，重新构建后即可生效。

## 常见排查

```bash
pm2 status
pm2 logs chaowen-blog
sudo systemctl status nginx
sudo nginx -t
sudo ss -ltnp | grep 3000
```

本地图片必须位于 `public/images/`，front matter 使用 `/images/...`，不要写 `src/public/...`。构建失败时可删除 `.next` 后重新执行 `npm ci && npm run build`。
