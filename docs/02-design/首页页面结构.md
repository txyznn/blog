# 首页页面结构

## 页面框架

首页使用单页纵向布局，外层为白色内容容器，页面背景为浅蓝灰色。桌面端内容最大宽度为 `1440px`，移动端自动铺满屏幕。

## 1. 顶部导航

- 左侧：Chaowen 图片 Logo。
- 中间：首页、文章、分类、标签、关于我、归档。
- 右侧：搜索按钮、主题切换按钮、订阅按钮。
- 移动端：导航链接折叠为菜单按钮，点击后展开移动导航。

## 2. Hero 首屏

- 英文身份提示：`HELLO, I'M CHAOWEN`。
- 主标题：`记录思考，分享成长。`
- 简介：介绍作者关注设计、生活和自我成长。
- 两个 CTA：阅读最新文章、认识我。
- 社交链接：GitHub、微信、CSDN（暂不展示具体社交主页）。
- 背景：浅蓝色渐变叠加山湖风景图。

## 3. 最新文章

文章列表位于首页主体左侧，每篇文章包含：

- 文章封面图。
- 文章分类标签。
- 标题。
- 摘要。
- 发布日期。
- 阅读时长。

当前示例文章包括个人网站、长期主义、生活记录和阅读笔记等主题。

## 4. 右侧信息栏

桌面端位于最新文章右侧，包含四个信息模块：

### 关于我

- 头像。
- 作者身份：设计师 / 写作者。
- 简短个人介绍。
- 更多关于我的链接。

### 热门标签

展示产品思考、阅读、日常、创作、旅行、设计、效率和播客等标签。

### 文章分类

展示设计、随笔、生活和阅读分类，以及对应文章数量。

### 归档

按月份展示文章数量，包括 2024 年 6 月、5 月和 4 月。

移动端右侧信息栏会移动到文章列表下方，并采用双列布局。

## 5. Newsletter 订阅

- 标题：`订阅我的来信`。
- 描述：说明邮件更新频率和内容方向。
- 邮箱输入框。
- 订阅按钮。
- 表单状态：订阅中、订阅成功、邮箱格式错误。

## 6. Footer

- Chaowen 图片 Logo。
- 版权信息。
- 关于、友链、隐私和 RSS 链接。
- GitHub、微信和 CSDN 链接（暂不展示具体社交主页）。

## 响应式行为

- `lg` 以上：显示完整导航、双栏主体和桌面操作按钮。
- `md` 到 `lg`：保留双栏内容，缩小间距和内边距。
- 移动端：导航折叠，Hero 改为单栏，文章封面缩小，侧栏移动到内容下方。

## 页面资源

- 导航和页脚 Logo：`src/asset/logo/logo-light.png`。
- 标签页图标：`src/app/icon.png`。
- 示例文章内容：`src/content/posts/hello-world.mdx`。
- 文章和 Hero 图片目前使用 Unsplash 远程图片。
