# Chaowen 博客项目概览

## 项目背景

这是一个个人博客项目，最初的灵感来自 Gates Notes：比尔·盖茨用于记录文章、观点和个人思考的平台。相比文章本身，我更关注这种以个人视角长期积累内容的方式，因此决定搭建一个属于自己的写作空间。

项目名称为 **Chaowen Notes**，网站使用域名 `txyznn.xyz`。`txyznn` 是作者长期使用的网络昵称，`.xyz` 与这个名称的简洁、开放感相契合。

## 项目定位

Chaowen 博客是一个面向个人创作者的内容型网站，主要用于记录设计、生活、自我成长和阅读思考。项目强调安静、克制和易阅读的视觉体验，不采用传统技术博客常见的高密度后台风格。

## 当前目标

- 建立一个稳定、易维护的个人博客基础。
- 使用 Markdown/MDX 管理文章，减少对 CMS 的依赖。
- 提供清晰的首页内容入口和文章浏览路径。
- 支持自有域名和自有服务器部署。
- 保持移动端和桌面端良好的阅读体验。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| Next.js 16 | React 应用框架、路由和构建 |
| React 19 | 页面组件和交互状态 |
| TypeScript | 类型检查和开发约束 |
| Tailwind CSS 4 | 页面布局和组件样式 |

## 当前页面能力

首页目前包含：

- 顶部导航：首页、文章、分类、标签、关于我、归档。
- Hero 首屏：Chaowen Logo、个人 Slogan、简介、文章入口和社交入口。
- 最新文章：图文文章列表、分类、摘要、日期和阅读时长。
- 侧栏信息：关于我、热门标签、文章分类和归档。
- Newsletter：邮箱输入、格式校验、订阅中和订阅成功反馈。
- Footer：Logo、版权、站点链接和社交入口。
- 响应式布局：移动端导航折叠，内容区域调整为单栏。

## 内容管理方式

文章文件统一放在：

```text
src/content/posts/
```

文章使用 `.mdx` 格式，可以编写标准 Markdown，也可以在文章中使用 React 组件。当前仓库包含一篇示例文章 `hello-world.mdx`。

首页文章列表现在会自动扫描 `src/content/posts/*.mdx`，读取 frontmatter 并按日期倒序展示。点击文章标题会进入 `/posts/[slug]` 详情页。

## 项目目录

```text
src/
├── app/                         # Next.js App Router 页面与全局样式
│   ├── page.tsx                 # 首页
│   ├── layout.tsx               # 根布局与 metadata
│   ├── globals.css              # 全局样式、颜色变量和 Hero 背景
│   └── icon.png                 # 浏览器标签页图标
├── asset/
│   ├── logo/                    # Chaowen 横版 Logo 及不同背景版本
│   └── favicon/                 # Favicon PNG 和 SVG 源文件
└── content/posts/               # MDX 文章
docs/                            # 项目设计、开发、内容和部署文档
scripts/                         # Logo 与 Favicon 资源生成脚本
next.config.mjs                  # MDX、图片域名和 Next.js 配置
postcss.config.mjs               # Tailwind CSS PostCSS 配置
tsconfig.json                    # TypeScript 配置
package.json                     # 依赖和运行命令
```

## 图片资源

Logo 和 Favicon 使用本地资源。首页文章封面和 Hero 图片目前使用 Unsplash 远程图片，远程域名通过 `next.config.mjs` 的 `images.remotePatterns` 配置。

后续使用自己的图片时，建议统一放入 `public/images/`，文章图片放在 `public/images/posts/`，再通过 `/images/posts/文件名` 引用。

## 部署方向

项目不再以 Vercel 作为默认托管方案，生产环境计划使用自有域名和自有服务器。服务器部署、域名解析、备案、HTTPS 和进程管理记录在：

```text
docs/05-deployment/自有服务器部署.md
```

## 当前限制

- 分类、标签和归档页面仍未从 MDX 自动生成。
- 搜索按钮和主题切换按钮目前是视觉占位。
- 社交链接暂时使用占位链接，不展示具体主页。
- Newsletter 目前只有前端交互，尚未连接真实邮件服务。
- 文章详情页已支持 `/posts/[slug]`，分类、标签和归档页面尚未建立独立路由。
